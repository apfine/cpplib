The vector have two things capacity which refers to the amount of the memory assigned to the vector and size refers to the number of elements present in the array.

The vectors have mainly some functions : 
    1. array.push_back() 
    2. array.pop_back()
    3. array.front()
    4. array.back()
    5. array.capacity()
    6. array.size()
    7. array.at()

While declaring a vector like this "vector <int> array(5,1)" 5 is the size of the array and 1 is the first element to be added in to the array.

---------------------------------------------------------------------///////////DEQUE\\\\\\\\-----------------------------------------------
It is dynamic .
Random access is possible .
The dque is a type of dataset which is a double queue .
This means that we can perform insertion and deletion at both the ends.
It is implemented using a complex method using many arrays and data is tracked using many other mechanisms which we dont need to know at this level.
It is the beast mode of a vector array in which we can push members from the front also from the back.
The methods related to a deque are : 
    1. deque.push_back()
    2. deque.push_front()
    3. deque.empty()
    4. d.last()
    5. d.erase()
    6. d.erase(d.begin() , d.begin()+1)                   //This method is used to erase the deque from front to end.
    7. While applying a for loop on the deque you can also use for(int i : d){} for iterating over the loop .
The feature of capacity do not changes even after using the erase function we have same capacity . It is somewhat similar to the vector arrays as above.

--------------------------------------------------------------------//////////List\\\\\\\\\\-------------------------------------------------
Random access is not possible.
It is dynamic .
This is what it sounds like and acts as so .
It is a linked list and the order of members do not matters and all the members have info about next and previous member.
The methods it have are as follows : 

    1. l.push_back()
    2. l.push_front()
    3. l.erase(l.begin() , l.begin()+1)
    4. l.size()

#Forward_list also exist in the STL which is differentiated by the fact that they are not doubly linked means we cannot go back from an element .
